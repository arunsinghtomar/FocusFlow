# FocusFlow — Smart Study Planner

**Plan smarter. Stay focused. Make progress every day.**

FocusFlow is a responsive, beginner-friendly study planner web application designed to help students organize their daily tasks, prioritize their work, and monitor their productivity through a clean and intuitive dashboard.

Built using HTML5, CSS3, and JavaScript, FocusFlow demonstrates essential frontend development skills, including DOM manipulation, event handling, responsive design, dynamic UI updates, and browser local storage.

## ✨ Features

- **Interactive Dashboard:** View total, completed, and pending tasks.
- **Task Management:** Add new tasks, mark them as completed, and delete them.
- **Priority Selection:** Organize tasks using High, Medium, and Low priority levels.
- **Task Filtering:** Filter tasks by All, Pending, or Completed status.
- **Search Functionality:** Quickly find tasks by their names.
- **Progress Tracking:** Monitor task completion through a dynamic progress bar.
- **Local Storage:** Keep tasks saved in the browser after refreshing the page.
- **Responsive Design:** Use the application on desktop, tablet, and mobile screens.
- **Clean User Interface:** Enjoy a modern dashboard with simple navigation and clear task information.

## 🛠️ Technologies Used

- HTML5 — Webpage structure and semantic elements
- CSS3 — Styling, layouts, animations, and responsive design
- JavaScript (ES6+) — Application logic and interactive features
- Browser Local Storage — Client-side task persistence

## 🚀 Getting Started

Follow these steps to run FocusFlow on your computer.

### Prerequisites

- A modern web browser
- Visual Studio Code or another code editor
- Optional: Live Server extension for VS Code

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/FocusFlow.git
   ```

2. Open the project folder:

   ```bash
   cd FocusFlow
   ```

3. Open the folder in Visual Studio Code.

4. Open `index.html` in your browser, or use the Live Server extension.

That's it! No backend server, package installation, or database configuration is required.

## 💡 How It Works

1. Enter a study task in the input field.
2. Select its priority level.
3. Click **Add Task** to add it to your task list.
4. Mark a task as completed when you finish it.
5. Use the filters or search field to find specific tasks.
6. Track your progress using the dashboard statistics and progress bar.

Tasks are stored in your browser's local storage. They are not synchronized across devices or browsers.

## 🎯 Project Objective

The goal of FocusFlow is to demonstrate how core frontend technologies can be combined to create a practical, responsive, and interactive web application.

The project provides hands-on practice with user interface design, JavaScript event handling, dynamic rendering, array operations, filtering, and client-side data persistence.
